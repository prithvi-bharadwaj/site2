  code; superseded by plan 003.
- *Add a Content-Security-Policy header*: static site, no user input, no auth,
  no API routes; a meaningful CSP for Next.js needs nonce plumbing or
  `'unsafe-inline'` script-src, which neuters it. Cost/benefit doesn't clear
  the bar today. Revisit if the site ever takes input or adds routes. (Note for
  any future attempt: fonts are self-hosted via `next/font` — no Google Fonts
  origins needed; `frame-src` must allow both `www.youtube.com` and
  `www.youtube-nocookie.com`.)
- *Upgrade `@chenglou/pretext` 0.0.3 → 0.0.8 for the DoS advisory*: the flagged
  algorithmic-complexity DoS requires attacker-controlled input; here the input
  is the site's own static hero copy, client-side. Breaking upgrade for no
  exploitable surface — skip until an API need arises.
- *`getContext("2d")` can return null → crash*: true per spec but effectively
  unreachable in browsers that run this site; folded into the lib-tests backlog
  item as hardening, not a standalone bug plan.
